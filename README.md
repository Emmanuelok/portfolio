# Emmanuel Kingsford Owusu — Portfolio

A motion-led portfolio for digital products, visual systems, web experiences, and design experiments.

## Run locally

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run typecheck
npm run lint
npm run build
```

The project uses Next.js App Router and is designed for Vercel deployment. No environment variables are required for the public portfolio.
